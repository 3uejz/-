# 指令动词表：life-text-sandbox

本文件是《浮生录》中文指令解析器的动词注册基线，配合 `requirements.md`（R27 指令解析）与 `design.md` 使用。指令结构为「动词 + 对象 + 参数」，动词可由内容包扩展。

## 通用与元指令

| 动词 | 别名 | 对象 | 参数 |
|------|------|------|------|
| 帮助 | help、? | 分类/动词 | 无 |
| 查看 | 看、查询 | 状态/背包/地图/关系/资产 | 分类 |
| 设置 | 配置 | 字号/对比/倍速/音量 | 值 |
| 存档 | 保存 | 槽位 | 名称 |
| 读档 | 加载 | 槽位 | 无 |
| 等待 | 等、挂机 | 无 | 时长 |
| 暂停 | 停 | 无 | 无 |
| 加速 | 倍速 | 无 | 1/2/4 |
| 快进 | 跳到 | 时点/事件 | 目标 |
| 重开 | 转生 | 无 | 无 |
