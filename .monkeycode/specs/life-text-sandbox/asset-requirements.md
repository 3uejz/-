# 美术资产需求清单：life-text-sandbox

面向「程序化占位 + 资产契约」路线：占位已可玩，本清单列出待供真实资产，按优先级分批。
所有资产遵循 `client/assets/README.md` 的目录结构、命名与 LOD 约定；放入约定路径即替换占位，**零改代码**。

## 0. 通用规范

| 项 | 约定 |
|----|------|
| 3D 格式 | glTF `.glb`（首选，单文件）；`.gltf` 次之 |
| 贴图 | `.png` / `.webp`；UI 图标可用 `.svg` |
| 音频 | 音乐 `.ogg`，短音效 `.wav` |
| 单位/朝向 | 米；Y 轴向上；模型面向 +Z |
| 三角面预算 | near ≤ 60k / mid ≤ 20k / far ≤ 5k（单场景） |
| 命名 | 全小写 + `_`；内容键点号转目录（`item.apple` → `models/item/apple.glb`） |
| LOD 命名 | `<name>_near` / `<name>_mid` / `<name>_far` |
| 许可 | 每个资产旁附 `<asset>.license.json`；`contentbuilder assets` 记录 sha256 |

| `education` | 学校/教室/图书馆 | 课桌、黑板、书架 |
| `government` | 政务/警局/法院 | 柜台、徽标、档案 |
| `transport` | 车站/机场/码头 | 检票、候车、指示牌 |

## 2. P1 — 角色与 NPC

- 玩家角色基础网格（可按性别/体型参数化），含简易骨骼与走/站/坐三类动画。
- NPC 通用模板（按年龄/职业/场合换装），首发 10–20 套变体。
- 交互动作：招手、递物、交谈、握手、鞠躬。

| 分类 | 代表 | 形态 |
|------|------|------|

| 工具器械 | 扳手、手机、电脑 | 小道具 |
| 服饰装备 | 衣、鞋、包、戒 | 可穿戴 |

## 4. P2 — UI 与主题

- 图标集（属性 6 组、技能域、菜单、状态、面板 Tab）。
- 面板九宫格底图（暗色/亮色/高对比/色盲友好四套皮肤）。
- 中文字体：正文/标题（需覆盖常用字，注意授权）。
- 状态条、徽章、进度环等组件皮肤。

## 5. P2 — 叙事插画

放入 `client/art/illustrations/<name>.(tres|png|svg|webp)`。

- 首发起步 30–50 张，覆盖：出生、求学、求职、婚育、疾病、灾祸、功成、衰老、死亡、传承。
- 风格：水墨留白为基调（缺失时自动回退同样留白占位）。
- 尺寸：横构图 1600×900 为主，方构图角色卡 1024×1024。

## 6. P3 — 音频

见内容全表 §16。

- 音乐：主界面、日间、夜间、紧张、重大事件、结局、传承，共 7 支起。
- 环境音：城市、室内、自然、雨雪、机械、人群。
- 音效：UI 点击/确认/警告、拾取、金币、升级、心跳、丧钟。

## 7. 验收与工具链

- 台账：`contentbuilder assets --dir <ART_DIR> --out ledger.json`（记大小/sha256/LOD/许可）。
- 校验：`scripts/test.sh` 硬阻断占位路径混入、命名违规与缺许可。
- 回归：替换任一资产后跑全量测试与一次 headless 场景加载，确认无脚本改动。
