# 浮生录 — 客户端 UI 技术设计

> 对应需求 R35、R57、R59；实施任务 `tasklist.md` 第 5、23 项。本文件是客户端界面的单一真源，`design.md`「UI Inventory」「UI 线框与交互流程」保留索引。

## 1. 定位与范围

- 桌面端单人自用，Godot 4 + GDScript。
- 视觉方向：**水墨国风**插画；暗色为默认，提供亮色主题；键鼠优先，手柄后置。
- 首发做满：全量 token 主题系统、45 个侧边抽屉面板、8 类关键弹窗、系统托盘与桌面通知、全套无障碍。
- 面板均以**侧边抽屉**滑出，可多开并排，不遮挡叙事流主体。

## 2. 设计 token 与主题系统

### 2.1 token 分类

所有视觉常量集中定义为 token，禁止组件内硬编码。

| 类别 | token 示例 |
|------|-----------|
| 颜色 | `color.bg.base`、`color.bg.panel`、`color.text.primary/secondary/disabled`、`color.border`、`color.accent`、`color.state.info/success/warning/danger` |
| 字体 | `font.family.body`（思源黑体）、`font.family.title`（思源宋体）、`font.size.*`、`font.weight.*`、`font.line_height.*` |
| 间距 | `space.xs/sm/md/lg/xl` |
| 圆角 | `radius.sm/md/lg` |
| 阴影 | `shadow.panel`、`shadow.modal` |
| 动效 | `motion.fast/normal/slow`、`motion.ease.*` |

### 2.2 主题

- **亮/暗双主题**，共用同一套语义 token 名，仅替换取值；两套均需通过 WCAG 对比度校验（正文 ≥ 4.5:1，大字号 ≥ 3:1）。
- **主题色定制**：允许在设置中选主色，派生 hover/active/禁用态。
- **无障碍主题**：默认 / 高对比 / 色盲友好三套，复用 `client/ui/settings/accessibility_palette.gd` 的语义配色与非颜色线索。
- 主题实现为 Godot `Theme` 资源 + token 字典，运行时切换；切换即时生效并持久化到设置。
- 水墨国风基调：宣纸底、墨色文字、朱砂/黛青点缀；插画采用留白、墨晕、竖排标题；界面控件保持克制以免喧宾夺主。

### 2.3 缩放与字号

- **全局 UI 缩放**：80% / 90% / 100% / 110% / 125% / 150% 档，作用于整个 UI 层。
- **正文字号**：独立档（小/中/大/特大），仅影响叙事流与表格正文，与全局缩放解耦。
- 高分屏默认按视口高度自动选档，用户可覆盖。

## 3. 主界面布局

```
┌───────────────────────────────────────────────────────────┐
│ 状态栏：日期时间 · 金钱 · 健康 · 主要需求 · 天气 · 倍速 · 暂停 │
├───────────────────────────────────┬───────────────────────┤
│                                   │  快捷动作面板          │
│   叙事流（可点击实体、内联插画）    │  （常驻按钮）          │
│                                   │                       │
├───────────────────────────────────┴───────────────────────┤
│ 指令区：中文输入框 · 前缀补全 · 历史 20 条 · 发送           │
└───────────────────────────────────────────────────────────┘
       侧边抽屉从右侧滑出，可多开并排
       模态弹窗居中，仅在关键决策时出现
```

- 状态栏常驻关键指标；详情进面板。
- 叙事流为信息主体，实体（人物/物品/地点）以可点击标记呈现。
- 快捷动作面板将常用动作做成按钮；文字、按钮、快捷键统一生成同一 `CommandIntent`（意图同源）。
- 面板层级：叙事流 < 侧边抽屉 < 模态弹窗 < 系统通知。

- 弹窗按钮支持键盘焦点与回车确认，满足无障碍。

## 6. 叙事流渲染

- **默认即时**整条显示；**可选打字机**逐字效果，默认关闭，可在设置开启；打字机播放中可点击跳过。
- 内联插画：关键事件在水墨国风插画中标出，点击可放大；插画随内容包分发。
- 实体标记：地点/物品/NPC 名称以可点击链接呈现，点击打开对应抽屉或旅行。
- 消息按语义着色并附非颜色线索（符号 + 类型标签 + 字重）。
- 历史消息虚拟滚动，超长会话分段加载，避免卡顿。

## 7. 地图与旅行交互

- 2D 可缩放地图承担跨场所导航；进入具体场所切换到局部 3D 探索（切换加载，非无缝开放世界）。
- 六级地理层级：世界 → 国家 → 区域 → 城市 → 街区 → 场所。
- 行程：选择起点终点后展示路径、耗时、费用与换乘，确认后推进时间并结算。
- 地图与面板一致支持无障碍配色与非颜色线索。

## 8. 无障碍（全套）

| 项 | 说明 |
|----|------|
| 字号与缩放 | 全局缩放 + 正文独立字号档 |
| 高对比 | 高对比主题，边框与焦点更明显 |
| 色盲友好 | Okabe-Ito 语义配色，状态不依赖色相 |
| 非颜色线索 | 每条消息带符号 + 类型标签 + 字重 |
| 键位重映射 | 所有可交互操作可自定义键位，含冲突检测 |
| 朗读 | 叙事流走系统 TTS，可开关与调速 |
| 减少动态 | 关闭打字机、淡入与滑动，改为瞬时切换 |
| 焦点导航 | 全键盘可完成主要流程，焦点环清晰可见 |

## 9. 通知与系统托盘

- **系统托盘常驻**：游戏可最小化到托盘继续按 1x 推进世界。
- **桌面通知**：上班、吃药、还款、约会等提醒触发系统通知，可分类开关。
- **游戏内**：消息流置顶 + 角标 + 挂机日志摘要。
- 通知点击可聚焦游戏窗口并跳转到对应面板。
- 安全阀：在线时健康低于危险阈值自动暂停并弹处理提示。

## 10. 主题设置页

- 分区：外观（亮/暗、主题色、水墨浓度）、字体（正文/标题、字号）、缩放、无障碍（对比/色盲/朗读/减少动态/键位）、通知（分类开关/托盘）、遥测开关。

## 12. 测试策略

- 主题：亮/暗与三套无障碍配色的对比度校验通过；切换幂等；token 无硬编码遗漏。
- 缩放：各缩放档与字号档下布局不溢出、不遮挡。
- 面板：45 个面板可开合、互不干扰（可多开）、空态与错误态正常。
- 弹窗：8 类流程可完成，键盘焦点可达，危险操作二次确认生效。
- 叙事：打字机开关、跳过、实体点击跳转正确。
- 无障碍：键位重映射冲突检测、TTS 开关、减少动态生效。
- 通知与托盘：触发条件、分类开关、点击聚焦正确。
