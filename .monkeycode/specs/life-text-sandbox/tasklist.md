> 任务 45（引擎定制基座与构建管线）、任务 46（共享数值基线单一真源）与任务 47（完整主题系统与 UI 全套）自 M0/M1 起与主线并行推进；M0–M2 开发继续使用官方引擎，不阻塞主线。

**排期与验收约定**

- 制作规模：你 + AI Agent；你负责决策、验收与内容策划，Agent 承担编码、工具链与脚手架。
- 排期方式：里程碑 + 验收，不锁日期；每个里程碑以产出与验收标准判定完成。
- 首版定义：单城垂直切片，在一座城市及其周边跑通「开档 → 学习 → 工作 → 存钱 → 买房 → 恋爱 → 结婚 → 死亡」完整闭环，核心系统可玩。
- 验收口径：
  - M0：中文指令、挂机实时世界、本地存档三项跑通，检查点可玩。
  - M1：地理、天气、经济、物品、NPC、职业、教育成形。
  - M2：人格精神、医疗、家庭传承、法律移民、娱乐、事件成就可玩。
  - M3：3D 表现层、内容管线、Go 后端与 Admin 后台可运行。
  - M4：社会系统与冲突战斗、世界记忆、音频等横切系统铺开。
  - M5：50 域全部测试通过。
