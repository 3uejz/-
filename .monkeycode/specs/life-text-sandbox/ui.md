# 浮生录 — 客户端 UI 技术设计

> 对应需求 R35、R57、R59；实施任务 `tasklist.md` 第 5、23 项。本文件是客户端界面的单一真源，`design.md`「UI Inventory」「UI 线框与交互流程」保留索引。

## 1. 定位与范围

- 桌面端单人自用，Godot 4 + GDScript。
- 视觉方向：**水墨国风**插画；暗色为默认，提供亮色主题；键鼠优先，手柄后置。
- 首发做满：全量 token 主题系统、12 个侧边抽屉面板、8 类关键弹窗、系统托盘与桌面通知、全套无障碍。
- 面板均以**侧边抽屉**滑出，可多开并排，不遮挡叙事流主体。

## 2. 设计 token 与主题系统

### 2.1 token 分类

所有视觉常量集中定义为 token，禁止组件内硬编码。

| 类别 | token 示例 |
|------|-----------|
| 颜色 | `color.bg.base`、`color.bg.panel`、`color.text.primary/secondary/disabled`、`color.border`、`color.accent`、`color.state.info/success/warning/danger` |
| 字体 | `font.family.body`（思源黑体）、`font.family.title`（思源宋体）、`font.size.*`、`font.weight.*`、`font.line_height.*` |
| 间距 | `space.xs/sm/md/lg/xl` |
| 圆角 | `radius.sm/md/lg` |
| 阴影 | `shadow.panel`、`shadow.modal` |
| 动效 | `motion.fast/normal/slow`、`motion.ease.*` |

### 2.2 主题

- **亮/暗双主题**，共用同一套语义 token 名，仅替换取值；两套均需通过 WCAG 对比度校验（正文 ≥ 4.5:1，大字号 ≥ 3:1）。
- **主题色定制**：允许在设置中选主色，派生 hover/active/禁用态。
- **无障碍主题**：默认 / 高对比 / 色盲友好三套，复用 `client/ui/settings/accessibility_palette.gd` 的语义配色与非颜色线索。
- 主题实现为 Godot `Theme` 资源 + token 字典，运行时切换；切换即时生效并持久化到设置。
- 水墨国风基调：宣纸底、墨色文字、朱砂/黛青点缀；插画采用留白、墨晕、竖排标题；界面控件保持克制以免喧宾夺主。

### 2.3 缩放与字号

- **全局 UI 缩放**：80% / 90% / 100% / 110% / 125% / 150% 档，作用于整个 UI 层。
- **正文字号**：独立档（小/中/大/特大），仅影响叙事流与表格正文，与全局缩放解耦。
- 高分屏默认按视口高度自动选档，用户可覆盖。

## 3. 主界面布局

```
┌───────────────────────────────────────────────────────────┐
│ 状态栏：日期时间 · 金钱 · 健康 · 主要需求 · 天气 · 倍速 · 暂停 │
├───────────────────────────────────┬───────────────────────┤
│                                   │  快捷动作面板          │
│   叙事流（可点击实体、内联插画）    │  （常驻按钮）          │
│                                   │                       │
├───────────────────────────────────┴───────────────────────┤
│ 指令区：中文输入框 · 前缀补全 · 历史 20 条 · 发送           │
└───────────────────────────────────────────────────────────┘
       侧边抽屉从右侧滑出，可多开并排
       模态弹窗居中，仅在关键决策时出现
```

- 状态栏常驻关键指标；详情进面板。
- 叙事流为信息主体，实体（人物/物品/地点）以可点击标记呈现。
- 快捷动作面板将常用动作做成按钮；文字、按钮、快捷键统一生成同一 `CommandIntent`（意图同源）。
- 面板层级：叙事流 < 侧边抽屉 < 模态弹窗 < 系统通知。

## 4. 面板规格（12 项）

| 面板 | 主要内容 | 关键交互 | 空态/错误态 |
|------|----------|----------|------------|
| 角色与属性 | 三大类属性、需求、健康、状态、人格 | 查看、按属性排序、查看来源与修正 | 无数据时提示「尚未生成」 |
| 技能树 | 多域技能等级与成长进度 | 展开领域、查看解锁条件、跳转学习 | 未解锁显示灰态与条件 |
| 背包与装备 | 物品分类、数量、品质、使用/装备/丢弃 | 使用、装备、丢弃、批量选择 | 背包为空提示可获取途径 |
| 关系与人脉 | 五维关系、NPC 详情、记忆、互动 | 查看详情、发起互动、标记亲疏 | 无关系时引导结识 |
| 地图 | 六级地理、缩放、地点导航、行程 | 缩放、点选地点、规划路线、开始旅行 | 未到访区域显示灰态 |
| 工作与职业 | 当前岗位、简历、求职、晋升、同事 | 求职、申请晋升、跳槽、查看绩效 | 无业时显示求职入口 |
| 资产与财务 | 现金、银行、投资、房产、负债 | 存取、转账、买卖、查看流水 | 无资产时引导工作 |
| 成就与图鉴 | 成就、图鉴、人生愿望 | 查看进度、领取、设为愿望 | 未达成显示进度条 |
| 家族史与传承 | 族谱、历代传说、世界记忆 | 浏览、回放关键事件、查看传承影响 | 首代显示始祖 |
| 异常图鉴 | 异常条目、收容等级、能力线、阵营声望 | 查看、追踪、管理收容物 | 未接触时整面板隐藏 |
| 金手指 | 系统任务、积分、抽取与升级、各模块 | 抽取、升级、签到、开关单条 | 未启用金手指模式时整面板隐藏 |
| 设置 | 字号、缩放、对比、色盲配色、主题色、键位、朗读、倍速、遥测、存档 | 实时预览、恢复默认、导入导出 | 保存失败给明确原因 |

- 异常图鉴与金手指属条件可见面板，未满足条件时不出现入口。
- 所有面板支持快捷键、按钮栏与中文指令三种打开方式。

## 5. 弹窗与流程（8 类）

| 弹窗 | 触发 | 要点 |
|------|------|------|
| 开档设定 | 新建存档 | 姓名、性别、出生地、家境、天赋；支持随机与保底重抽 |
| 事件选项 | 随机/剧情事件 | 展示选项、条件、后果提示；超时可选默认项 |
| 交易 | 买卖、议价 | 数量、单价、总价、税费、余额校验 |
| 对话 | NPC 交互 | 分支选项、关系影响、记忆写入 |
| 审判 | 法律事件 | 指控、证据、选择辩护、判决呈现 |
| 临终 | 死亡判定 | 确认死亡、回顾遗愿、遗嘱订立 |
| 人生总结 | 一世结束 | 总收入/支出、职业轨迹、主要成就、家族史写入 |
| 传承结算 | 进入下代 | 传承点数、可继承资产、子孙选择 |

- 关键决策弹窗不可被误关；危险操作需二次确认。
- 弹窗按钮支持键盘焦点与回车确认，满足无障碍。

## 6. 叙事流渲染

- **默认即时**整条显示；**可选打字机**逐字效果，默认关闭，可在设置开启；打字机播放中可点击跳过。
- 内联插画：关键事件在水墨国风插画中标出，点击可放大；插画随内容包分发。
- 实体标记：地点/物品/NPC 名称以可点击链接呈现，点击打开对应抽屉或旅行。
- 消息按语义着色并附非颜色线索（符号 + 类型标签 + 字重）。
- 历史消息虚拟滚动，超长会话分段加载，避免卡顿。

## 7. 地图与旅行交互

- 2D 可缩放地图承担跨场所导航；进入具体场所切换到局部 3D 探索（切换加载，非无缝开放世界）。
- 六级地理层级：世界 → 国家 → 区域 → 城市 → 街区 → 场所。
- 行程：选择起点终点后展示路径、耗时、费用与换乘，确认后推进时间并结算。
- 地图与面板一致支持无障碍配色与非颜色线索。

## 8. 无障碍（全套）

| 项 | 说明 |
|----|------|
| 字号与缩放 | 全局缩放 + 正文独立字号档 |
| 高对比 | 高对比主题，边框与焦点更明显 |
| 色盲友好 | Okabe-Ito 语义配色，状态不依赖色相 |
| 非颜色线索 | 每条消息带符号 + 类型标签 + 字重 |
| 键位重映射 | 所有可交互操作可自定义键位，含冲突检测 |
| 朗读 | 叙事流走系统 TTS，可开关与调速 |
| 减少动态 | 关闭打字机、淡入与滑动，改为瞬时切换 |
| 焦点导航 | 全键盘可完成主要流程，焦点环清晰可见 |

## 9. 通知与系统托盘

- **系统托盘常驻**：游戏可最小化到托盘继续按 1x 推进世界。
- **桌面通知**：上班、吃药、还款、约会等提醒触发系统通知，可分类开关。
- **游戏内**：消息流置顶 + 角标 + 挂机日志摘要。
- 通知点击可聚焦游戏窗口并跳转到对应面板。
- 安全阀：在线时健康低于危险阈值自动暂停并弹处理提示。

## 10. 主题设置页

- 分区：外观（亮/暗、主题色、水墨浓度）、字体（正文/标题、字号）、缩放、无障碍（对比/色盲/朗读/减少动态/键位）、通知（分类开关/托盘）、遥测开关。
- 所有改动**实时预览**，可一键恢复默认，可随存档配置保存。

## 11. 工程结构

```
client/ui/
├── theme/            # token 定义、Theme 资源、主题切换器
├── components/       # 通用控件（抽屉、弹窗、表格、语义标签、插画框）
├── layout/           # 状态栏、叙事流、指令区、快捷动作、帧结构
├── panels/           # 12 个面板
├── dialogs/          # 8 类弹窗
├── map/              # 地图与旅行交互
├── settings/         # 设置与无障碍
├── onboarding/       # 新手引导
└── notifications/    # 游戏内通知与托盘集成
```

- 视图与模拟解耦，headless 下可加载 UI 壳。
- 主题 token 与 `shared/consistency/vectors/baseline.json` 无关；纯视觉常量走主题资源。

已落地的纯逻辑基座（任务 47）：`theme/theme_tokens.gd`（token 真源与三套配色 × 亮暗）、`theme/theme_builder.gd`（token→Theme 资源与缩放/字号档）、`theme/theme_lint.gd`（无硬编码检查）、`components/panel_registry.gd`（12 面板开合/条件可见/焦点）、`components/dialog_registry.gd`（8 弹窗互斥/二次确认）、`layout/typewriter.gd`、`notifications/notification_prefs.gd`、`settings/settings_model.gd`（键位/TTS）、`settings/accessibility_palette.gd`（对比度与非颜色线索）。对应测试 `client/tests/theme_test.gd`、`ui_behavior_test.gd`。

主壳端到端切片（任务 47.4）：`theme/theme_manager.gd`（运行时主题切换并 `apply_to` UI 根）、`panels/panel_content.gd`（把 GameState 玩家字典装配为面板行数据，与视图解耦）。`ui/main.gd` 在 `_ready` 应用主题、创建 `Root/Drawers` 抽屉容器与面板入口按钮；`open_panel/close_panel/toggle` 支持多开并排；快捷动词经 `VERB_PANELS` 与文字指令同源打开面板。已打通「角色与属性」「背包与装备」「技能树」「工作与职业」「资产与财务」「关系与人脉」「成就与图鉴」「家族史与传承」「地图」「设置」十个常驻面板（设置面板含切主题/配色/主色的实时预览控件）；异常图鉴、金手指为条件可见面板，待对应状态接入。名称解析可注入内容注册表 Callable，离线回退 content_key。关键弹窗经 `DialogRegistry` 接入主壳 `DialogLayer`（遮罩 + 居中面板，层级高于抽屉）：模态互斥、危险弹窗二次确认、不可关闭弹窗禁用关闭按钮；`open_dialog/confirm_dialog/close_dialog` 为对外接口。对应测试 `client/tests/panel_content_test.gd`、`ui_shell_test.gd`。

## 12. 测试策略

- 主题：亮/暗与三套无障碍配色的对比度校验通过；切换幂等；token 无硬编码遗漏。
- 缩放：各缩放档与字号档下布局不溢出、不遮挡。
- 面板：12 个面板可开合、互不干扰（可多开）、空态与错误态正常。
- 弹窗：8 类流程可完成，键盘焦点可达，危险操作二次确认生效。
- 叙事：打字机开关、跳过、实体点击跳转正确。
- 无障碍：键位重映射冲突检测、TTS 开关、减少动态生效。
- 通知与托盘：触发条件、分类开关、点击聚焦正确。
